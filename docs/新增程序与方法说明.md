# 新增程序与方法说明

> 本文档用于说明本次新增或调整的程序、方法和脚本，方便在新设备上继续开发和调试。
> 这里只写“做了什么、在哪、怎么用”，不写实验结果。

## 1. 新增的核心程序

### 1. `PromptLanguageRules`

路径：`memind-core/src/main/java/com/openmemind/ai/memory/core/prompt/PromptLanguageRules.java`

作用：
- 统一控制提示词语言规则
- 让写入、检索、回答时的语言风格更稳定
- 便于在不同场景下切换中文/英文表达

### 2. `QueryAwareResultPrioritizer`

路径：`memind-core/src/main/java/com/openmemind/ai/memory/core/retrieval/scoring/QueryAwareResultPrioritizer.java`

作用：
- 根据用户问题调整结果排序
- 让更相关的记忆排到前面
- 用来增强检索结果的可读性和命中率

### 3. `QueryAwareResultPrioritizerTest`

路径：`memind-core/src/test/java/com/openmemind/ai/memory/core/retrieval/scoring/QueryAwareResultPrioritizerTest.java`

作用：
- 验证排序逻辑是否正常
- 确保后续修改不会把结果排序搞乱

### 4. `OpenMemoryApplicationService` 超时调整

路径：`memind-server/src/main/java/com/openmemind/ai/memory/server/service/memory/OpenMemoryApplicationService.java`

调整内容：
- 把写入、抽取、检索使用的内部等待时间从 60 秒改成 10 分钟
- 这样更适合较长的记忆写入提交过程

作用：
- 降低 commit 阶段因为处理时间过长而返回 500 的概率
- 让较复杂的 session 有更高概率完整写入

## 4. 新增内容的使用方式

### 写入记忆

1. 启动后端
2. 运行单条写入脚本测试
3. 再运行批量写入脚本
4. 用验证脚本检查是否真正落库

### 做问答测试

1. 先运行问答生成脚本
2. 再运行评测脚本
3. 查看汇总结果和明细

### 调试时的注意点

- 修改 `.env` 后，要重新加载环境变量再启动后端
- 新终端建议使用隔离环境运行脚本，避免旧配置干扰
- API Key 和模型配置不要直接写进代码里

## 6. 简单总结

这次新增的内容主要是两类：

1. **功能代码**：提示词语言规则、结果排序规则、后端超时调整、对应测试
2. **支撑工具**：写入、验证、问答、评测脚本

它们的目标都是让 Memind 的写入、检索和测试流程更稳定、更容易接续开发。
