# 记忆写入说明

> 本文只说明“记忆写入”这一件事：怎么启动、怎么写、怎么验证、相关模块在哪。
> 不记录实验结果，不展开知识图谱细节。

## 1. 写入目标

把会话内容写入 Memind，让后续检索和问答可以直接命中相关记忆。

## 2. 相关模块

| 模块                                                | 作用                       |
| --------------------------------------------------- | -------------------------- |
| `memind-server`                                   | 接收写入请求、执行 commit  |
| `memind-core`                                     | 抽取、链接、排序的核心逻辑 |
| `dev-tools/python/generate_benchmark_memories.py` | 批量写入脚本               |
| `dev-tools/python/write_one_session.py`           | 单 session 写入脚本        |
| `dev-tools/python/verify_company.py`              | 写入后验证                 |

## 3. 基本流程

1. 启动后端
2. 选择公司和 session
3. 逐条发送消息
4. commit 触发抽取
5. 用验证脚本检查是否真正落库

## 4. 常用命令

### 启动后端

```bash
cd /home/zzx/py/Memind-Local-Dev
set -a && source .env && set +a && mvn -pl memind-server spring-boot:run
```

### 单条写入测试

```bash
cd /home/zzx/py/Memind-Local-Dev
env -i HOME="$HOME" PATH="$PATH" python3 dev-tools/python/write_one_session.py \
  --company C010 --session S001 \
  --id-prefix benchmark-v107 --source-client benchmark-v107
```

### 批量写入

```bash
cd /home/zzx/py/Memind-Local-Dev
env -i HOME="$HOME" PATH="$PATH" python3 dev-tools/python/generate_benchmark_memories.py \
  --server http://127.0.0.1:8366 \
  --benchmark-dir "/mnt/d/CCBwork/2026/8月/benchmark_v1_0_7/standard/quick" \
  --companies C010 C011 C012 C013 C014 \
  --id-prefix benchmark-v107 \
  --source-client benchmark-v107
```

## 5. 验证方式

```bash
cd /home/zzx/py/Memind-Local-Dev
env -i HOME="$HOME" PATH="$PATH" python3 dev-tools/python/verify_company.py --companies C010 C011 C012 C013 C014
```

## 6. 注意事项

- `.env` 改了以后，要在同一终端重新 `source .env` 再启动后端。
- 写入前建议先做单条测试。
- 看到 `SUCCESS` 还要确认 `itemIds` 和 `verify` 结果，避免假成功。
