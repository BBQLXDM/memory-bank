# Memind 功能说明总览

> 这是一份面向新设备/新接手人员的简明说明。
> 只保留当前主要功能、相关模块和启动/测试入口；实验结果、周报和评测产物不在这里展开。

## 主要功能

- **记忆写入**：把会话内容写入 Memind，并生成可检索记忆。
- **问答测试**：先生成检索+回答结果，再做评测。
- **知识图谱**：作为独立说明保留，不放在搬运主线里。

## 相关模块

| 模块 | 作用 |
|---|---|
| `memind-core` | 记忆核心逻辑、抽取、检索、排序 |
| `memind-server` | 后端服务，提供记忆写入与查询接口 |
| `memind-plugins` | JDBC、模型、rawdata 等插件 |
| `dev-tools/python` | 写入、验证、问答、评测脚本 |
| `docs/` | 功能说明与使用说明 |

## 常用入口

- 后端启动说明：`LOCAL_START_COMMANDS.md`
- 记忆写入说明：`docs/记忆写入说明.md`
- 问答评测说明：`docs/问答评测说明.md`

## 当前注意点

1. 启动后端时要加载 `.env`，避免旧环境变量干扰。
2. 写入和测试都建议先做单条验证，再做批量执行。
3. 知识图谱说明单独保留，不纳入主搬运范围。
